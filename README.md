# Assignment 1: Java Modular Utilities

An object-oriented Java application structured with separate packages and classes for individual utility tasks, executed via a central Driver class.

## 🚀 Key Features
- Grade Calculator: Converts numerical course scores to letter grades (A, B, C, D, F).
- Distance Converter: Converts Miles to Kilometers.
- Volume Converter: Converts Liters to Gallons.
- Currency Converter: Converts Canadian Dollars (CAD) to US Dollars (USD).

## 🛠️ Tech & Architecture
- Language: Java
- OOP Concepts: Package bundling, class separation, and object instantiation to call methods.
- Input: Java `Scanner` for user inputs.
